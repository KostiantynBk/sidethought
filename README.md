# Sidethought

Sidethought is a text-first, voice-later thinking partner for solo builders that keeps researching while you talk, speaks up only when it matters, and never repeats advice whose basis has changed.

All code in this repository is written during the Meta Global AI Developer Hackathon build window, starting 2026-10-27.

## Getting started

Use Node 24 or newer, then run `npm install` and `npm test`. Run `npm run typecheck` to check types.

**Status:** Stage 2a — kernel and replay harness in progress.
